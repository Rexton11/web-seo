# Транскрибатор видео

Локальный веб-инструмент для транскрипции видео с YouTube и загруженных файлов.

## Установка

```bash
cd video-transcriber
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Также нужен ffmpeg:
```bash
# Ubuntu/Debian
sudo apt install ffmpeg

# macOS
brew install ffmpeg
```

## Запуск

```bash
source .venv/bin/activate
python app.py
```

Открой http://localhost:5000 в браузере.

## Возможности

- **YouTube** — вставь ссылку, аудио скачается автоматически
- **Загрузка файла** — drag-and-drop или выбор файла (MP4, MKV, MP3, WAV и др., до 500 МБ)
- Автоопределение языка
- Копирование и скачивание результата

## Модели Whisper

По умолчанию используется модель `base` (быстрая, приемлемое качество). Для лучшего качества измени в `app.py`:

| Модель | Размер | Качество |
|--------|--------|----------|
| `tiny` | 39 МБ | Быстро, низкое качество |
| `base` | 74 МБ | Баланс скорости и качества |
| `small` | 244 МБ | Хорошее качество |
| `medium` | 769 МБ | Высокое качество |
| `large` | 1.5 ГБ | Максимальное качество |
